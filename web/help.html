How the pages work

A lesson page has some reading, and cells of C# that you can change and run. The C# runs in your browser, on this device. Nothing you write is sent anywhere.

A cell

A cell is a box of C# code. You can change the code, then press Run. What the program prints appears under the cell.

The label at the top of a cell says what kind of cell it is:

  • program: a program. It has statements, lines that do something, such as Console.WriteLine("Hi");. Run runs it. While it runs, the button says Stop.
  • types: a cell with only classes (or records, interfaces, enums and structs) in it. There is nothing to run, so the button says Check. Check reads the code and shows any compiler messages.

Next to the label is the cell's file name, such as Program.cs. The compiler uses it in its messages.

Reset puts the page's own code back in the cell. If you pressed it by mistake, click in the code and press Ctrl+Z (Cmd+Z on a Mac): your code comes back.

The first time, the page downloads C# (about 15 MB). A line at the top of the page says how far it has got. After that, this device keeps it.

Three things can happen when you press Run

Before C# runs a program, it reads all of it and checks it. That is compiling. Then:

  1. It did not compile, so nothing ran. The compiler found a problem. It says where, in a message like this one: 
    Program.cs(2,19): error CS0103: The name 'totl' does not exist in the current context
    That is the file, the line (2), the column (19), the error's code (CS0103), and what the compiler found. Click a message to go to that line. Read the first message first: one mistake can cause several messages. A warning is shown in grey. A warning never stops a program.
  2. It stopped with an exception. The program ran until a line it could not complete, such as reading item 3 of a list with two items. The page says which line. Click the line to go to it.
  3. It ran. It ran from the first line to the last. Whether it did what you wanted is for you to decide.

A program that runs for 30 seconds without finishing is stopped. A loop that never ends is the usual reason. Time spent waiting for you to type does not count.

When a program asks you something

Console.ReadLine() waits for you to type, as it does in a real console. A box appears under the output, and the cursor moves into it. Type your answer and press Enter. End input tells the program that there is nothing more to read: Console.ReadLine() then gives null.

A few browsers cannot pause a program while you type. On those, a box above the Run button asks for all the answers first, one on each line.

The rules of the road: how cells share code

A page has many cells. These five rules say what one cell can use from another.

1. Each Run starts a new program.

It runs from the first line of the cell to the last.

int count = 1;
count = count + 1;
Console.WriteLine(count);   // 2, every time you press Run

2. A class written in a cell can be used by the cells below it.

So can an interface, a record, an enum or a struct.

// A cell above:
public class Planet
{
    public string Name { get; set; }
}

// A cell below can use it:
Planet mars = new Planet { Name = "Mars" };
Console.WriteLine(mars.Name);

3. Variables stay in their cell.

Nothing a cell's statements made is there for the next cell. To use a value again, make it again.

// A cell above:
int score = 10;

// A cell below. This does not compile (CS0103),
// because score stayed in its cell.
Console.WriteLine(score);

4. A class written again further down replaces the earlier one.

The cells below the new one use the new one.

// Cell 1:
public class Greeter
{
    public string Hello() => "Hi";
}

// Cell 2:
public class Greeter
{
    public string Hello() => "Hello there";
}

// Cell 3 prints "Hello there":
Console.WriteLine(new Greeter().Hello());

5. Main stays in its cell, like statements.

A class with a static void Main is a program of its own. The cells below do not get it.

class Greeter
{
    static void Main()
    {
        Console.WriteLine("Main ran.");
    }
}

Guesses, hints and solutions

  • A guess. Some cells ask what you think the program will print, and how sure you are: sure, a hunch, or I'm not sure yet. After you run it, your guess and the output are shown side by side. The page does not mark your guess. A difference is something to look at.
  • A hint appears under a cell after you have tried, for example after two runs that did not compile. A small ? at the top of some cells has a hint too.
  • A solution is behind a fold. Open it when you want to see one way to do the task. Yours may be different and work too.
  • Compare with a solution runs your code and a solution with the same inputs, and shows what each one gives. Rows that give different values are marked different.
  • Worlds. Some pages let you choose a world under the title, such as a game or the solar system. The task is the same size in each. The page remembers your choice.

The keyboard

  • Ctrl+Enter (Cmd+Enter on a Mac) or Shift+Enter in a cell: Run.
  • Tab in a cell indents the line. To move on from the cell with the keyboard, press Escape, then Tab.
  • Ctrl+Z undoes a change, and Ctrl+F finds text in a cell.
  • Every button can be reached with Tab and pressed with Enter or Space.

Your work

The page saves your code and your guesses in this browser, on this device, as you type. When you come back, they are still there. If the page has changed since you saved your work, a note at the top says so.

Some computers, such as lab computers, clear browser data when you log out. To keep your work, press Export my work at the bottom of a page. It saves a file with all of your work. Next time, press Import my work and choose the file.

My notebook is a place for your own C#: code cells and text cells, in as many notebooks as you like. The same rules of the road apply there. Download project on a program cell saves it as a Visual Studio project, which you can open and run in Visual Studio.

Settings

Settings at the top of each page changes the colours (light or dark), the contrast, the font, the text size, the width of the lines, and movement on the page. There are two fonts that some people find easier to read: Lexend and OpenDyslexic. The settings stay on this device. dewlab uses the same settings.

If C# does not start on a device, Check this device tests each part and says what to try.
